or inference. Root's pre-inference context-delivery amendment introduced two
literal newline characters into five current requests. The CLI's existing input
contract rejects those control characters. This is an evaluation setup defect;
it is not a model answer failure. The initial artifacts and 48-case denominator
remain unchanged, and the original collection continues to completion.

The statically affected IDs are `fresh_035`, `fresh_036`, `fresh_044`,
`fresh_046`, and `fresh_047`. Authoring and scoring criteria do not change. A

with a space; all remaining content, history and rubrics stay identical. This
normalization is declared before reviewing any answer from those requests.
No production code, model, settings, source freeze or meaningful answer changes.

Eligibility is mechanical: the original row must have status `error`, exact
`ValueError` message `user message cannot contain control characters`, no route,
no calls and no delivered reply. If any named row fails that check, it is not
silently retried; a further explicit accounting decision would be required.
No ordinary routing error, wrong answer, unnecessary clarification, timeout,
truncation, or poor model-review decision qualifies for this follow-up.

once in its original relative order, under the same guarded launcher and source
freeze, in a separately named directory with a new isolated empty store.
