# Candidate changes

Baseline is commit `e398548`, whose clean sixteen-case recovery passed four
strict answer-quality judgments. Those same sixteen prompts are development
cases in this cycle; they cannot establish unseen-case generalization.

The candidate repairs four concrete failure classes:

- Prior-value requests no longer become supplied personal facts merely because
  the user says they want their earlier choice. The independent execution guard
  still requires current authorized evidence even after an incorrect general
  route. Empty retrieval produces an explicit missing-information response.
- Bounded target, pronoun and unit ambiguity checks ask for the missing choice.
  Explicit selections, supplied referents and complete conversions retain their
  ordinary answer path.
- Typed answer parts support requested numbering, literal line labels, explicit
  CSV headers, names on separate lines and integer-only results. Rendering adds
  source-derived structure; raw model output remains available. Quoted examples
  and negated instructions do not supply formatting authority. CSV parts are
  data rows when an explicit source header is rendered, including data rows
  whose text happens to equal that header.
- Shortening an admitted event draft checks requested word limits, weekdays,
  clock values, numbered locations and event subject before model review.
  Explicit weekday ranges no longer cause the named-recipient history guard to
  discard an otherwise admitted public event draft. Unrelated previous answers
  and personal records do not become draft sources.

Generation instructions emphasize concrete deliverables and preserving supplied
quantities, materials and times. A bounded Earth day/night topic note is grounded
in [NASA's explanation](https://starchild.gsfc.nasa.gov/docs/StarChild/questions/question31.html),
reviewed on 17 September 2026. This is application knowledge, not personal memory
or a general factual-verification guarantee.

The existing two-attempt ceiling, model identities, context/output budgets,
temperature, evidence checks and device guards remain unchanged. Independent
evaluation reconstruction validates added formatting against the recorded source
request and rejects content additions. Lexical draft and ambiguity checks remain
bounded heuristics; passing them is not proof that an arbitrary answer is correct.

Validation and measured outcomes are recorded separately after each cohort.
Voice/transcription, end-to-end audio latency and live populated-memory behavior
are outside this text-answer evaluation.
