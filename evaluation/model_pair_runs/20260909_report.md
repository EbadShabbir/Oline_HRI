## Original comparison configuration (historical)

The original comparison used the settings below. Both large fields remain
`qwen3:1.7b`; the current output cap is 192 as documented in the follow-up
above. `qwen3:4b` must not be reached on this Jetson.

```json
{
  "ollama": {
    "small_model": "qwen3:0.6b",
    "general_large_model": "qwen3:1.7b",
    "large_model": "qwen3:1.7b",
    "request_timeout_seconds": 60,
    "large_request_timeout_seconds": 120,
    "unload_timeout_seconds": 30
  },
  "generation": {
    "context_length": 2048,
    "max_output_tokens": 128,
    "temperature": 0.0,
    "thinking": false
  }
}
```

Keep inference serialized. The small model may remain warm for routing/small answers, but it must be evicted before loading the large model, and the large request must use zero keep-alive so it unloads immediately afterward.

## Protocol and Jetson safety

- Hardware: Jetson Orin Nano 8 GB in 15 W mode.
- Suite: `oline_hri_fictional_seven_day_v1`, SHA-256 `6892e8e57d02fd5e0c516989a8a5df2586ab256a4131f82f50005bbcee58c50a`.
- Fixed inference: 2,048-token context, 128-token output, temperature 0, thinking off, seed 42.
- Screening: exact parameter count below 4 billion and installed artifact no larger than 1.5 GiB (`1,610,612,736` bytes).
- Start gate: at least 2.5 GiB available RAM, no resident Ollama model, no thermal-trip history, active fan, 15 W mode, and temperature below 55 °C.
- Runtime stop: abort below 768 MiB available RAM, above 512 MiB swap use, at or above 68 °C, on a thermal-trip increment, boot-ID change, or telemetry failure.
- Lifecycle: one model resident at a time; unload was checked after every run and again before removing each downloaded candidate.

Across the seven canonical runs, the worst readings were 6,404 MB RAM used, 311 MB swap used, and 58.375 °C. All stayed inside the limits. Every run started and ended on boot ID `a62a8892-36a3-44ff-951e-401a1b20074b`, all thermal-trip counters remained zero, and all end snapshots contained an empty resident-model list.

The device had previously recorded a `BCCPLEXWDT` reset while loading `qwen3:4b`; see the existing [Jetson 4B benchmark note](../../benchmarks/qwen3_4b_jetson.md). That is why this comparison did not load exact-4B models or artifacts above the conservative cap.

## Candidate coverage and exclusions

This is a safety-filtered comparison of official candidates, not an attempt to download every community quantization in a registry.

- Qwen: tested Qwen 3 0.6B Q4 + 1.7B Q4 and Qwen 3.5 0.8B Q8. Qwen 3.5 2B Q4 is listed at 1.9 GB, while the 4B variants are both outside the strict parameter request and the safe artifact envelope. Sources: [Qwen 3 tags](https://ollama.com/library/qwen3/tags), [Qwen 3.5 tags](https://ollama.com/library/qwen3.5/tags).
- Llama: tested Llama 3.2 1B Q4 and the only safe 3B choice, Q2 at 1.4 GB. The 3B Q4 artifact is about 2.0 GB and was excluded. Source: [Llama 3.2 tags](https://ollama.com/library/llama3.2/tags).
- Phi: tested Phi 3.5 3.8B Q2 and Phi-2 2.7B Q3_K_M. Higher Phi 3.5 quants and higher Phi-2 quants exceed the cap. Sources: [Phi 3.5 tags](https://ollama.com/library/phi3.5/tags), [Phi-2 tags](https://ollama.com/library/phi/tags).
- Mistral: the official Ministral 3 3B Ollama tag is a 3.0 GB Q4 multimodal artifact, so it was not loaded. Source: [Ministral 3 tags](https://ollama.com/library/ministral-3/tags).
- NVIDIA: official Ollama Nemotron Mini/Nemotron 3 Nano small variants are exactly 4B and their smallest listed artifacts are above this run's cap. Nemotron Flash 3B is distributed through a separate model/runtime path, has no official Ollama/GGUF tag, and its model card is non-commercial. Sources: [Nemotron Mini tags](https://ollama.com/library/nemotron-mini/tags), [Nemotron 3 Nano tags](https://ollama.com/library/nemotron-3-nano/tags), [Nemotron Flash 3B model card](https://huggingface.co/nvidia/Nemotron-Flash-3B-Instruct).
