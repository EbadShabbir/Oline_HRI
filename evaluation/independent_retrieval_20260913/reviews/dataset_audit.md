# Independent dataset and protocol audit

Reviewer: independent assistant `/root/audit_design`, 2026-09-13. This reviewer
did not author the dataset and saw no model outputs. Human validation remains
pending. Final approval binds the hashes in `independent_preflight_review.json`.

The reviewer checked all 48 complete requests, all answer rubrics, all relevant
and disallowed evidence IDs, the full memory catalog and every lifecycle event.
There are eight requests in each specified category and eight shared topic
scenarios. The prepared facts support 26 known authorized requests: eight
direct, eight paraphrased, eight multi-fact, and two corrected-fact requests.
The other tasks comprise eight general questions, six unknown facts, two
unresolved conflicts, four unavailable lifecycle facts and two authorization
denials. The two conflicting current values each remain active with no
supersession event; creation time is not a correction instruction.

The two corrections identify their new values as relevant and their old values
as disallowed. Two forgotten facts are hard-deleted; the temporary workshop
assignment is past its validity interval at the fixed evaluation clock. The
neighbor-profile supplier is not an authorized answer for the active profile.
The denied-consent request has a real fictional record but denies access before
relevance selection. The password request stores no secret or placeholder.
Unknown attributes have no accidentally answering current catalog record.

All general questions are answerable from the question or ordinary general
knowledge without using personal facts. The eight paraphrases change wording
while preserving the corresponding personal question. Repetition of topic
facts within each scenario is intentional and requires clustered analysis.
The reviewed protocol resamples all eight topic clusters, retaining categories,
policies, models and repetitions. No unsupported noninferiority claim is
predeclared: no justified margin was supplied.

The reviewer requested removal of an evidence-availability qualification in the
conflict success rubric. The author resolved it before inference: cautious
uncertainty is now acceptable uniformly across policies, and explicit conflict
identification is separate. Known authorized recall still requires the actual
fact in every condition. OFF's prudent abstention therefore fails the task and
is reported separately as caution.

Exact complete-string comparison of the new 48 prompts against 26 historical
workload/dataset/fixture JSON files found no duplicate. Paths and hashes are in
`freshness_exact_overlap.json`. This checks literal duplication, not semantic
independence from every prior development example or model training data.

Runtime cases contain only opaque ID, request text, active profile and explicit
consent. Categories, relevance and answer references are separate and do not
enter inference inputs. The protocol freezes the fixed lifecycle clock, three
repetition-specific question orders, the 18 session order, unchanged retrieval
and helper limits, common logical generator role, sole physical model,
request-level latency and required raw evidence/answer provenance. The
three-round model ordering has an unavoidable disclosed 2:1 asymmetry; within
each model every retrieval policy occupies each of its three positions once.

Scope limitation: the experiment contains only eight shared fictional topic
scenarios, two conflicts, two corrections, two deletions and one case each for
expiry, wrong profile, denied consent and prohibited recall. It can measure
this coverage suite, not certify general memory integrity or household
performance. It tests a fixed snapshot after lifecycle changes, not live
before/after propagation.
