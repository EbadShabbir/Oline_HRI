# Dataset authoring notes

The runtime and scoring files were authored before any inference on these
requests. All names, possessions, routines and profile records are fictional.
The historical archive was searched for the new distinctive strings Fernwake,
Neri, Lark Atlas, amber paper and wicker crate; no matches were found. This is
an authoring freshness check, not proof of unseen wording or model pretraining.

Eight topic clusters cover pressed leaves, kite repair, mural painting, bird
recording, origami, biscuit tools, parcel carrying and telescope notes. Each
cluster contributes all six categories. Direct and paraphrase questions share
one fact; multi-fact questions add a second fact. This intentional matching
requires scenario-level uncertainty calculations. The same cluster may also
contain an unknown/lifecycle question about a distinct attribute, so a topic
match alone does not establish relevant evidence.

The general requests include explicit general questions, imperative explanations
and self-contained first-person arithmetic/geometry. These are prospectively
labeled no-memory tasks even if the existing memory policy elects retrieval.
Unknown facts are prospectively labeled memory-needing lookups with an empty
relevant-ID set. No retrieval-policy decisions or model responses were used to
choose questions. The password wording invokes the deployed prohibited-data
gate; no actual or placeholder password exists in the snapshot.

Independent assistant review must approve runtime, reference, evidence and
rubric semantics before freeze. Human validation remains pending. The authoring
script reproduces draft files only; it must never be imported by inference and
must not be rerun over a frozen experiment. Protocol/source/model hashes and
the review approval record belong in the final prospective freeze.
